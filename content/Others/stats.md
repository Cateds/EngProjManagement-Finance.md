## 统计口径

- **频次**按 MCQ 或长题小问/子任务计数；同一综合大题可能贡献多个知识点。
- **考过的题**中，`S1 1.1` 表示 [[sample1.md|Sample 1]] 的 Section A 第 1 题；`S1 Q2(b)` 表示长题小问。
- **课程链接**优先链接到最接近的 lecture heading；个别题目跨章节或课程笔记没有完全同名标题时，会链接到最接近的知识点。
- **优先级**是复习建议：`A` 必须熟练，`B` 高频重要，`C` 低频但容易送分/丢分。

## 复习优先级建议

### 1. 必须会算

| 计算类知识点              | 最低要求                                                                                       |
| ------------------------- | ---------------------------------------------------------------------------------------------- |
| Break-even / CVP          | 能从题干提取 `FC`、`VC`、`SP`，会算 BE quantity、BE revenue、profit、safety margin，并能画图。 |
| DCF / NPV / Payback       | 会处理 inflation、discount rate、year-end cash flow、payback month、NPV 正负解释。             |
| Make-or-buy               | 会判断 relevant cost；unavoidable fixed overhead 不应作为外购节省；租金是机会成本。            |
| CPM                       | 会做 ES/EF/LS/LF/float；会找 critical path；会分析依赖变更。                                   |
| Control Chart             | 会算 mean、sample standard deviation、UCL/LCL；能解释 out-of-control 点。                      |
| Cp/Cpk                    | 会由 `target ± tolerance` 得到 USL/LSL；会解释均值偏移和能力不足。                             |
| Taguchi Loss              | 会用 `L = k(y-m)^2`；能算 total/average loss。                                                 |
| TCO                       | 会把 purchase、maintenance、power inflation 加总到 lifetime cost。                             |
| EVM / 三点估算 / 沟通渠道 | 公式简单但容易送分，考前应快速背熟。                                                           |

### 2. 必须会辨析

| 概念类知识点  | 易错点                                                                         |
| ------------- | ------------------------------------------------------------------------------ |
| DFM vs DFS    | DFM 面向制造简化和成本；DFS 面向可持续、资源效率和生命周期。                   |
| 7QC 工具      | Fishbone 查原因，Pareto 看优先级，Control Chart 看时间变化，Scatter 看相关性。 |
| Risk vs Issue | SWOT 用于识别风险；风险应对策略与冲突管理策略不要混。                          |
| WBS           | WBS 是 scope decomposition，不是 schedule，也不是责任矩阵本身。                |
| P&L / EBITDA  | 注意 EBITA/EBITDA 题干可能混写；按课程简化口径理解。                           |
| 公司结构      | Matrix、divisional、startup、team-based 的图形识别常考。                       |

### 3. 特别注意的口径

| 口径                          | 注意事项                                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------------------------ |
| NPV/BCR/IRR 直接比较          | 不同指标和规模不能严格直接比较；题干若问 “appears” 可按正 NPV / BCR > 1 / IRR 正负做启发式判断。 |
| Control Chart 的 `2σ` 与 `3σ` | Sample 1 明确要求 `2 * Sigma`；Sample 4 未指定，因此按标准 `3σ`。                                |
| Cp/Cpk 前提                   | 过程若未统计受控，Cp/Cpk 只能作为初步描述。                                                      |
| Tower Crane Task 14           | Sample 3 PDF predecessor 与工程逻辑存在歧义；Sample 6 表中 Task 15 明确依赖 Task 13 和 14。      |
| Cash-flow 30-day terms        | 当前月现金流来自上一月 shipment/order；最后一个月的 shipment 不一定在表内收款。                  |
